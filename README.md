## Publish

In repository Settings → Pages → Build and deployment, choose **GitHub Actions**. The included workflow builds, checks and deploys `dist` on every push to `main`. No paid hosting, API key or package dependency is required. The repository name means the site lives at `/github.io/`, not the account root.

## Edit

Run `python scripts/build.py`, then `python scripts/check.py`. Article JSON lives in `content/`; assets live in `dist/assets/`. Commit source and regenerated output together. Read EDITORIAL.md before publishing. Do not commit local preview symlinks or `.openai` configuration.

## Discoverability

HTML is rendered ahead of time, with unique descriptions, canonical URLs, Person and BlogPosting structured data, an XML sitemap and RSS. After deployment, verify the URL-prefix property in Google Search Console and Bing Webmaster Tools and submit `https://hope284.github.io/github.io/sitemap.xml`. Verification requires the owner's account. These features help discovery; they do not guarantee indexing, positions or inclusion in AI answers.
